# Hospital Management Website

A responsive Hospital Management Website built with HTML, Tailwind CSS, and JavaScript. The project includes dedicated dashboards for patients, doctors, and administrators, providing a clean and user-friendly interface for managing healthcare services.

## Description

This project demonstrates modern frontend development practices by creating a responsive healthcare platform with intuitive navigation and organized dashboard layouts.

## Features

- Responsive design
- Patient Dashboard
- Doctor Dashboard
- Admin Dashboard
- Appointment Management Interface
- Modern User Interface

## Technologies

- HTML5
- Tailwind CSS
- JavaScript

## Installation

```bash
git clone https://github.com/onuegbuchinelom-wq/Hospital-Management-Website.git
cd Hospital-Management-Website
```

Open `index.html` in your browser or run the project using the VS Code Live Server extension.
